# TaskFlow Kanban

Quadro Kanban no estilo Trello, desenvolvido com React + TypeScript para a disciplina de Desenvolvimento Mobile (Mackenzie).

- Drag-and-drop de cartões e colunas com `@dnd-kit`
- Edição inline de títulos e etiquetas coloridas
- Estado global com Zustand e persistência no `localStorage`
- API REST em Node + PostgreSQL
- Execução completa via Docker Compose

O planejamento completo está em [`docs/PLANEJAMENTO.md`](docs/PLANEJAMENTO.md).
